ReleaseLens

Upload a JUnit XML file and get a plain-English answer to “can we release?” — a GREEN / YELLOW / RED verdict, failures grouped by reason, and the tests to re-check first.

No account, no chat. The report is one page, written for managers and product owners as well as engineers.

If you list the files you changed, the report adds a deterministic “tests to run first” ranking: name overlap with those files, recent failure rate, and flaky status. No LLM is used for the ranking.

“Try with a sample” analyses the real-bug sample: 25 tests with a critical login bug. A person should still confirm the verdict before release.
